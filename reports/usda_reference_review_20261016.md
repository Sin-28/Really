## Nutrient provenance and approval boundary

The JSON manifest preserves each measured nutrient's FDC nutrient identifier, USDA nutrient name, original unit, amount, and imported nutrition basis. Sodium, potassium, and phosphorus use only FDC nutrient IDs 1093, 1092, and 1091 respectively; protein uses ID 1003. Phosphate is not treated as phosphorus. A nutrient absent from the catalog or recorded in an unsupported unit is not used as a normalized comparison value.

The `decide` CLI previews by default. A persistent approval or rejection requires `--confirm-persist`, an explicit reviewer identity, provenance, and an entry in the generated manifest. Even an approved reference remains separate from a VERIFIED ingredient mapping and cannot confirm recipe constraints.
